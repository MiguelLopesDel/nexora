# AUR packaging

This directory mirrors what gets pushed to the AUR git repo
(`ssh://aur@aur.archlinux.org/nexora.git`) — it is not built automatically by
this repo's CI. Update it by hand after cutting a release tag.

## After tagging a new release (`vX.Y.Z`)

1. Compute the real tarball checksum and drop it into both `PKGBUILD` and
   `.SRCINFO`:
   ```bash
   curl -sL https://github.com/MiguelLopesDel/nexora/archive/refs/tags/vX.Y.Z.tar.gz \
     | sha256sum
   ```
2. Bump `pkgver` (and reset `pkgrel=1`) in `PKGBUILD`.
3. Regenerate `.SRCINFO` from an actual Arch machine — the AUR only accepts
   one generated by `makepkg`, not hand-edited:
   ```bash
   makepkg --printsrcinfo > .SRCINFO
   ```
4. Build and lint locally before publishing:
   ```bash
   makepkg -si   # build + install, sanity check it actually works
   namcap PKGBUILD .SRCINFO
   ```
5. Push to the AUR (separate remote, needs an AUR account + registered SSH
   key — not something this repo's git remote can do):
   ```bash
   git clone ssh://aur@aur.archlinux.org/nexora.git aur-nexora
   cp PKGBUILD .SRCINFO aur-nexora/
   cd aur-nexora && git add PKGBUILD .SRCINFO && git commit -m "nexora X.Y.Z" && git push
   ```

## GPU backend

The package builds with the default Cargo feature (`whisper-vulkan`), which
covers current Intel/AMD/NVIDIA Linux drivers. Users who need `whisper-cuda`
or `whisper-rocm` should build manually per the README rather than through a
separate AUR package, until there's real demand for one.
